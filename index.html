จัดการ Code บรรจุภัณฑ์

Code คือชุดบรรจุภัณฑ์ที่ตั้งไว้ล่วงหน้า พอเลือก Code ตอนบันทึกขาย ระบบจะหักสต๊อกบรรจุภัณฑ์ตามที่ผูกไว้ให้อัตโนมัติ ไม่ต้องติ๊กเลือกเองทุกครั้ง
ยังไม่มี Code — กด "+ เพิ่ม Code" เพื่อสร้างอันแรก
